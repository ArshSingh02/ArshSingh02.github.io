Center for Neurotechnology – University of Washington

Machine Learning Intern

May 2023 – August 2023 · Seattle, WA

Overview

Developed machine learning and signal-processing methods for classifying stages of consciousness during anesthesia emergence using intracranial EEG recordings.

Machine Learning

Designed and trained linear discriminant analysis models in Python to classify different stages of consciousness during anesthesia emergence.

Signal Processing

Applied FFT-based spectral analysis across brain regions to derive predictive features from intracranial EEG signals.

Built a preprocessing workflow using band-pass filtering to reduce noise and remove low-quality electrode channels.

Results

Achieved 93% label accuracy by refining time-domain and frequency-domain features and tuning model hyperparameters.
