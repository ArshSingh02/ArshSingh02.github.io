Reinforcement Learning Search and Rescue Robot

July 2026

C++ • ROS 2 • Isaac ROS • Reinforcement Learning • NVIDIA Jetson • cuVSLAM • YOLO • Nav2

Overview

Developed a C++ autonomous mobile robot using Isaac ROS to execute reinforcement learning policies for autonomous object search in indoor environments.

The project combines perception, visual SLAM, mapping, navigation, object detection, Bayesian reasoning, and reinforcement learning into an end-to-end robotic system deployed on NVIDIA Jetson hardware.

Autonomy Stack

The robot uses ROS 2 and Isaac ROS as the foundation of its autonomy stack. Visual localization and mapping are performed using cuVSLAM, while Nav2 handles autonomous navigation through the mapped environment.

YOLO-based object detection processes camera observations to identify relevant objects while the robot searches the environment.

Reinforcement Learning

Designed a custom Gymnasium environment for training an autonomous search policy using Maskable PPO.

The environment incorporates Bayesian belief updates and action masking so that the policy can use observations from previous search locations to determine where the robot should search next.

Evaluation

The learned policy was evaluated against a greedy search baseline across 10,000 randomized evaluation episodes.

The reinforcement learning policy reduced average search time by 13% compared with the greedy baseline.

Deployment

Deployed the complete autonomy stack on an NVIDIA Jetson, integrating localization, mapping, navigation, perception, and learned search policies on the physical robot.
