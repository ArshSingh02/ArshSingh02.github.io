Embedded ECG & Temperature Monitor

May 2025

C • Zephyr RTOS • BLE • ADC • I²C • PWM • Embedded Systems

Overview

Developed an embedded physiological monitoring system using C and Zephyr RTOS for real-time ECG acquisition, heart-rate computation, temperature sensing, battery monitoring, and wireless communication.

ECG Acquisition

Developed firmware to sample ECG signals through the microcontroller's ADC and process the incoming samples in real time to calculate heart rate.

Real-Time Software Architecture

Implemented an event-driven state machine using Zephyr RTOS threads, timers, and kernel events to coordinate sensor acquisition and system control flow.

This architecture allowed sensing, processing, communication, and system-status operations to execute concurrently while maintaining predictable system behavior.

Sensors and System Monitoring

Integrated an I²C temperature sensor alongside battery monitoring functionality.

PWM-controlled LEDs provided real-time feedback for device status and error conditions.

Bluetooth Low Energy

Built a Bluetooth Low Energy communication stack to transmit heart rate, temperature, and system status to external devices.

The implementation used both standard and custom GATT services to expose physiological measurements and device-specific status information.
